Meet Vector & Relational SQL

ShrestiDB is an embedded database kernel that replaces bulky B-Trees with learned regression models and SIMD vector search — delivering 8x–10x faster lookups and a 4x smaller memory footprint in a single binary.

🧠

Learned PGM & RMI Indexing

Treats key indexing as an ML regression problem. Predicts exact tuple offsets with bounded linear segments, scaling flatly at O(log ε) while saving 75% RAM over B-Trees.

📐

Native SIMD Vector Engine

High-dimensional embeddings with Hierarchical Navigable Small World (HNSW) proximity graphs. Accelerated by AVX2/NEON SIMD cosine, L2, and dot product distances.

⚡

ACID MVCC & Learned Auto-GC

Snapshot-isolated transactions with row-level 2PL and write-ahead logging (WAL). Online regression models predict version bloat to sweep dead tuples without manual VACUUM.

FROM accounts a

Zero-Dependency Rust Embedded Engine main.rs 
use shrestidb::execution::QueryExecutor;

fn main() -> anyhow::Result<()> {
    // Durable engine backed by Write-Ahead Log (WAL)
    let db = QueryExecutor::open("shrestidb.wal")?;

    // Execute SQL statements directly
    let rows = db.execute_sql(
        "SELECT * FROM accounts WHERE balance >= 5000;"
    )?;
    Ok(())
}
